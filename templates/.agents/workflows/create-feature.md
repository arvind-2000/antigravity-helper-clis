
# Create Flutter Feature

## Objective
Implement a complete, maintainable Flutter feature that follows the existing project architecture.

## Step 1: Analyze
- Inspect the project structure and `pubspec.yaml`.
- Identify the existing state management and routing solutions.
- Examine similar existing features.
- Identify reusable widgets, services, repositories, and models.
- Check whether required dependencies are already installed.

## Step 2: Plan
- Define the feature's responsibilities.
- Identify required screens, widgets, models, and state.
- Determine API or database requirements.
- Identify loading, empty, success, and error states.
- Present a concise implementation plan before major changes.

## Step 3: Implement
- Follow existing project conventions.
- Reuse existing components.
- Keep UI separate from business logic.
- Use typed models.
- Handle null values and exceptions safely.
- Implement responsive layouts.
- Avoid unnecessary dependencies and unrelated changes.

## Step 4: Verify
- Run Dart formatting.
- Run `flutter analyze`.
- Run relevant tests.
- Fix issues introduced by the implementation.
- Check navigation and important user interactions.

## Step 5: Report
Summarize:
- Feature implemented.
- Files created or modified.
- Architectural decisions.
- Commands and tests executed.
- Remaining issues.

## Restrictions
- Do not overwrite unrelated code.
- Do not change the project's architecture without justification.
- Do not expose credentials or secrets.
- Do not deploy or perform destructive operations without approval.
